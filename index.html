    Under varje bild står var sidan kom ifrån i originalet (V = vänster halva, H = höger halva). Klicka på krysset uppe till höger för att ta bort en sida, till exempel en tom sida. Klicka igen för att ångra. Filerna uppdateras automatiskt.

    Bygger på pdf-lib och pdf.js. Öppna sidan direkt från hårddisken eller via GitHub Pages. Ingen server behövs.
