Skrivhäftesfix

Delar skannade A3-skrivhäften (liggande) i stående A4-sidor och sorterar om dem i läsordning. Filen lämnar aldrig din dator: allt sker i webbläsaren.

Under varje bild står var sidan kom ifrån i originalet (V = vänster halva, H = höger halva).

Bygger på pdf-lib och pdf.js. Öppna sidan direkt från hårddisken eller via GitHub Pages. Ingen server behövs.
